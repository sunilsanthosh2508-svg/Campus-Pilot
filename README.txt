# Campus Pilot Brand Website

A responsive one-page brand/landing website for Campus Pilot.

## Customize
1. Open `index.html`.
2. Replace `PASTE_YOUR_GOOGLE_FORM_LINK_HERE` with your Campus Pilot Google Form URL.
3. Open `index.html` in a browser to preview.

The site intentionally describes product capabilities as planned directions/what we're building rather than claiming they already exist.
